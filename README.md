# 存档·网文版

> 全虚构长篇。素材是一段真实聊天记录的脱敏重建：十四万条消息，四年七个月，两个人——她有两个账号。
> 人物、地名、学校、时间、事件、对话全部新建。原始素材只提供人际力学与情绪骨架，一个字都不搬运。

## 一句话

一段只活在对话框里的关系：靠打字维持，靠换号续命，家长的删除键就是分手键。

## 两个人

- 男主：**陆迟**。陆是陆地，迟是迟到。他留在原地。
- 女主：**程遥**。程是路程，遥是远。她越走越远。
- 她的两个账号：旧号**满座**，新号**空椅**。同一个人，两套档案。

## 与《答案》的分工

同源，不同枝。

- 《答案》写的是**没说出口**。纸上的、向后的、抒情的。核心句是"我给的喜欢，都写在纸上，藏在不敢说出口的地方"。
- 《存档》写的是**说了四年也没能落地**。屏上的、实时的、口语的。核心句是"我们什么都聊过，就是没有一起生活过"。

《答案》的信物是瓶里的纸星星；《存档》的信物是一张写着旧地址的快递单，和一个没有删的文件夹。

命名同源不同温：沈聿 / 江苒 是水的书，陆迟 / 程遥 是陆与路的书。详见 `设定/04_姊妹篇衔接.md`。

## 与《答案》的关系

两书门在同一张地图上：禾塘县属雾山市，与南雾县邻县。共用雾山后街、雾山大学、南雾老街。两对主角永不相遇、永不相识。

彩蛋共六处，全部埋在本书一侧（详见 `设定/05_同世界观彩蛋.md`），不解释、不点名。

## 卷目

| 卷 | 章号 | 功能 |
|---|---|---|
| 卷一 雪花 | 01-20 | 寒假热恋，她的不安，第一次断联 |
| 卷二 重连 | 21-40 | 复合，同校，见不到面的春天 |
| 卷三 双影 | 41-60 | 第二个账号出现，家长接管，删好友 |
| 卷四 深夜 | 61-80 | 重逢，地下，每周只活一天 |
| 卷五 时差 | 81-100 | 大学，她的家，出国 |
| 卷六 存档 | 101-120 | 只剩快递、游戏和账目，最后一次投递 |

卷名的隐喻是信号：雪花是无信号的屏，重连是恢复，双影是两个她，深夜是只在夜里上线，时差是物理与心理的距离，存档是最后能留下的东西。
