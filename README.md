# 存档

> 全虚构长篇。素材是一段真实聊天记录的脱敏重建：十四万条消息，四年七个月，两个人。
> 人物、地名、时间、事件、对话全部重建。原始素材只提供人际力学与情绪骨架，一个字都不搬运。

## 一句话

一段只活在对话框里的关系：靠打字维持，靠换号续命，家长的删除键就是分手键。

## 两个人

- 男主：**闻迟**。闻是听见，迟是迟到。他听见得晚。
- 女主：**程遥**。程是路程，遥是远。她越走越远。
- 她的两个账号：旧号**满座**，新号**空椅**。同一个人，两套档案。

## 与《答案》的关系

同源，两个机位。

- 《答案》是作者自己的故事。《存档》写的是他一位同学的故事。
- 两个男生在现实里是高中同班，所以两个故事长在同一张地图上。
- 《答案》原版第 34 章曾用一段话写过《存档》的男主（“走的不仅仅是他的女朋友，还有他的魂魄”）。本书要做的，就是把那段话展开。
- **两台摄像机**：《答案》从外面看，《存档》从里面看。同一件事，一个机位看到悲剧，另一个机位看到地下工作。

两书共用雾山市 / 南雾县 / 市三中 / 雾山大学 / 后街夜市，不共用任何私有信物。彩蛋共六处，全埋在本书一侧，不解释、不点名。

详见 `设定/05_同世界观彩蛋.md` 与 `设定/04_姊妹篇衔接.md`。

## 与《答案》的关系

两书长在同一张地图上：共用雾山市、南雾县、市三中、雾山大学、后街夜市。两本书的主角永不相遇、永不相识。

彩蛋共六处，全部埋在本书一侧（详见 `设定/05_同世界观彩蛋.md`），不解释、不点名。

## 卷目

| 卷 | 章号 | 功能 |
|---|---|---|
| 卷一 雪花 | 01-20 | 高一寒假的热恋，她的不安，第一次断联 |
| 卷二 重连 | 21-40 | 转学，同校不同班，见不到面的春天 |
| 卷三 双影 | 41-60 | 第二个账号出现，家长接管，好友被删 |
| 卷四 深夜 | 61-80 | 重逢，地下，每周只活一天 |
| 卷五 时差 | 81-100 | 大学，她的家，出国 |
| 卷六 存档 | 101-120 | 分手谈判，分手后的合伙人关系 |

卷名的隐喻是信号：雪花是无信号的屏，重连是恢复，双影是两个她，深夜是只在夜里上线，时差是物理与心理的距离，存档是最后能留下的东西。

全书的重心在卷六：前五卷的所有铺垫，都是为了第113到117章那五十分钟。
