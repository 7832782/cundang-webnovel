## 脚本使用红线

改中文文本一律用 edit 工具。内联 python 会被中文引号截断；更危险的是表达式写错会整文件覆写。已经因此弄坏过一一次台账（靠 git show 恢复）。任何写文件的 python 脚本，先 print 目标内容再写，或者干脆不用。
