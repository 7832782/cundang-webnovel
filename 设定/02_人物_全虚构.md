# 人物（全虚构新建）

> 以下所有人物均为本书新建，与现实无关。允许一维轻映射（结构 / 意象 / 声母），禁止同字、禁止同音全同、禁止事实复刻。

## 主角

**陆迟（男主，第一人称「我」）**
- 映射说明：只保留"独姓 + 单字名、尾字收得沉"的结构。用字全换。
- 名字的字面：陆是陆地，迟是迟到。他站在陆地上没动，永远晚一条消息。
- 与《答案》男主的关系：沈有深水，陆是陆地。一个是沉在水底的笔，一个是留在岸上的钉子。
- 性格底色：慢，绕，事后才想明白。不会当面表达，但能对着屏幕说很多。工科，爱修旧东西，写东西比说话利索。
- 标志动作：打了一段话又全删；紧张时反复刷新对话框；把重要的东西存两份。
- 缺点：总觉得还有下一次，总把该说的话往后拖。以为"在"就等于"在场"。
- 成长线：从「一直在」到发现「一直在」不够，从「等她开口」到「自己去把话说完」。

**程遥（女主）**
- 映射说明：保留结尾字的时间感与距离感（对应《答案》里江苒的"苒"），换成同方向的另一个字，不留同字同音。
- 名字的字面：程是路程，遥是远。她的名字本身就在说，这一路很长。
- 账号：她有两个，旧号和新号。两个号是同一个人。
- **但昵称不固定**：她在每个号上的展示名一年一换，甚至更勤。换名字对她而言是换皮肤，是表达欲续命的方式。有的名字很凶，有的很软，有的带着商品标签式的版本后缀。
- 全书不为她的账号名做统一设定。每一卷她叫什么，按那一卷的处境定，见 `设定/06_语言质地.md`。
- 账号名的来历（正文中不点破，靠读者自己撞见）：两个号不是她设计出来的一对，是日子自己配对上的。一个开在谁都在的时候，一个开在人走空了的时候。
- 头像：最初是一朵拍糊的花，隔着玻璃拍的。后来换过很多次。
- 与《答案》女主的区别：江是水，会流走；程是路，会走远。江苒是一株渐渐长起来的草，程遥是一条越走越远的路。
- 性格底色：外面一层刺，里面极度自我否定。骂人如呼吸，撒娇也用骂人的句法。语文好，画画好，爱看番、玩谷子，活得热闹，心里空。
- 标志动作：连着发很多条短句；说狠话之后立刻撤回；半夜忽然出现，说一句"睡了吗"。
- 口头禅（虚构）：「滚」「你懂个屁」「算了」「我死了」。
- 成长线：从「把所有寄托压在一个人身上」到「先把自己捡回来」，从「不停离开」到「终于说清楚为什么离开」。

两人关系钩：他慢，她快。她负责把关系弄响，他负责把关系接住。她把真话藏在玩笑里，他把真话存在文件里。

## 人物的两个隐藏刻度

**一、称呼的降级曲线。** 他叫她，从最高频的两个亲昵称呼，一路降到卷六的零称呼，只剩「好」「行」。她叫他，从名字到专属昵称到「哥哥」，卷六回落到「哥们」「老弟」。

「老公」这个词全程只出现过几次，从未转正。叫过，但没叫稳。这是这段关系没走完的那半步。

**二、名字的两种活法。** 她一年换一个名字，他四年只换过三个标点。她靠换皮肤续命，他靠不换维持。这是两个人性格的极简对照，也是全书最安静的一条时间轴。

详见 `设定/06_语言质地.md`。

## 虚构配角（只映射功能）

- **程梨**：她的妹妹。被家里偏爱的那个。功能：照出她家那杆秤不平。
- **程家阿婆**：她的外婆。她从小跟着阿婆。唯一对她好的人。功能：她世界里唯一的暖。
- **周奕**：两人的老同学，男生，话多，人缘好。功能：共同记忆的载体，也是误会的来源（他随口一句话能让两个人各想一晚）。
- **何叶**：她的女生朋友，念的是同校文科。功能：替她说话、传话，也是唯一见过她真实状态的人。
- **顾南**：她的旧追求者，后来一直没走开。功能：男主心里那根刺。全书只出现四次，且从未与男主正面对话。
- **阿枝**：她的另一个朋友，网感强，带她入坑谷子。功能：气氛与时代感。
- **陈树**：男主大学室友。功能：把话说破的人。全书男主唯一一次听劝，来自他。
- **陆家奶奶**：男主的奶奶。不识字，记得每次是谁打电话来。功能：家的锚点。
- **她的父母**：不写职业、不写单位。只写行为：双标的秤、骂人的句子、"你妹妹还小"。

## 命名系统（两部书同源不同温）

《答案》是水的书：沈（深水）、江（河流），卷目也是蝉鸣、回潮、潮汐、退潮。
《存档》是陆与路的书：陆（陆地）、程（路程），卷目换成雪花、重连、双影、深夜、时差、存档。

两部的男主姓氏形成一组：一个在水里沉的笔，一个在陆上留的钉子。
两部的女主结尾字形成一组：苒是草木渐长（时间感），遥是路远（时间与空间双关）。

同一个作者的手，两种温度：《答案》偏高、偏纸面、偏向后；《存档》偏低、偏屏面、偏实时。

## 排列规则

- 全书只写三个人在场以上的场景不超过十次。这是一部两个人的书。
- 程遥的心理永不直写。她只通过打字、停顿、撤回、行动呈现。
- 配角不加真实原型备注。没有原型。
- 命名一致性：她家并现时加姓（程家阿婆、程梨），男主家加姓（陆家奶奶）。

## 禁止事项

- 不得在人物小传里写真实学校、真实专业、真实去向、真实城市。
- 不得写「原型是某某」。
- 不得为任何配角添加现实对照说明。
