# 人物（全虚构新建）

> 以下所有人物均为本书新建，与现实无关。允许一维轻映射（结构 / 意象 / 声母），禁止同字、禁止同音全同、禁止事实复刻。

## 主角

**陆迟（男主，第一人称「我」）**
- 映射说明：只保留"独姓 + 单字名、尾字收得沉"的结构。用字全换。
- 性格底色：慢，绕，事后才想明白。不会当面表达，但能对着屏幕说很多。工科，爱修旧东西，写东西比说话利索。
- 标志动作：打了一段话又全删；紧张时反复刷新对话框；把重要的东西存两份。
- 缺点：总觉得还有下一次，总把该说的话往后拖。以为"在"就等于"在场"。
- 成长线：从「一直在」到发现「一直在」不够，从「等她开口」到「自己去把话说完」。

**温遥（女主）**
- 映射说明：保留"名字里有距离感、有温度的反差"这一方向，用字全换，不留同字。
- 两个名字：旧号叫**山茶**，新号叫**空椅**。两个号是同一个人。
- 性格底色：外面一层刺，里面极度自我否定。骂人如呼吸，撒娇也用骂人的句法。语文好，画画好，爱看番、玩谷子，活得热闹，心里空。
- 标志动作：连着发很多条短句；说狠话之后立刻撤回；半夜忽然出现，说一句"睡了吗"。
- 口头禅（虚构）：「滚」「你懂个屁」「算了」「我死了」。
- 成长线：从「把所有寄托压在一个人身上」到「先把自己捡回来」，从「不停离开」到「终于说清楚为什么离开」。

两人关系钩：他慢，她快。她负责把关系弄响，他负责把关系接住。她把真话藏在玩笑里，他把真话存在文件里。

## 虚构配角（只映射功能）

- **温梨**：她的妹妹。被家里偏爱的那个。功能：照出她家那杆秤不平。
- **温家阿婆**：她的外婆。她从小跟着阿婆。唯一对她好的人。功能：她世界里唯一的暖。
- **周奕**：两人的老同学，男生，话多，人缘好。功能：共同记忆的载体，也是误会的来源（他随口一句话能让两个人各想一晚）。
- **何叶**：她的女生朋友，念的是同校文科。功能：替她说话、传话，也是唯一见过她真实状态的人。
- **顾南**：她的旧追求者，后来一直没走开。功能：男主心里那根刺。全书只出现四次，且从未与男主正面对话。
- **阿枝**：她的另一个朋友，网感强，带她入坑谷子。功能：气氛与时代感。
- **陈树**：男主大学室友。功能：把话说破的人。全书男主唯一一次听劝，来自他。
- **陆家奶奶**：男主的奶奶。不识字，记得每次是谁打电话来。功能：家的锚点。
- **她的父母**：不写职业、不写单位。只写行为：双标的秤、骂人的句子、"你妹妹还小"。

## 排列规则

- 全书只写三个人在场以上的场景不超过十次。这是一部两个人的书。
- 温遥的心理永不直写。她只通过打字、停顿、撤回、行动呈现。
- 配角不加真实原型备注。没有原型。
- 命名一致性：她家并现时加姓（温家阿婆、温梨），男主家加姓（陆家奶奶）。

## 禁止事项

- 不得在人物小传里写真实学校、真实专业、真实去向、真实城市。
- 不得写「原型是某某」。
- 不得为任何配角添加现实对照说明。
