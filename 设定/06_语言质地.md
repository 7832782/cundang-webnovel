# 语言质地（写作校准器）

> 本文件是《存档》写作时的语气标尺。数据来自对原始聊天记录的全量词频扫描与 25 个精读窗口，方法可复核。
> 全部结论已脱敏，不含任何真实姓名、账号名、日期。数字只保留量级与比例关系。

## 一、称呼演变（关系史的刻度）

这是一段**称呼在不断降级**的关系。写下这条曲线，全书的温度就定了。

**他叫她**

| 阶段 | 称呼 | 量级 |
|---|---|---|
| 卷一 | 老婆、宝宝 | 峰值期，最高频 |
| 卷二 | 老婆、宝宝 | 仍高，制度化 |
| 卷三 | 老婆、宝宝 | 开始降温 |
| 卷四 | 老婆、宝宝 | 骤降 |
| 卷五 | 几乎不用 | 归零 |
| 卷六 | 基本零称呼 | 只剩「好」「行」 |

**她叫他**

| 阶段 | 称呼 | 备注 |
|---|---|---|
| 卷一 | 名字 + 老式昵称 | 开始 |
| 卷二 | 宝宝 | 复合期 |
| 卷三 | 专属昵称（小的那个） | 只有她这么叫他 |
| 卷四 | 哥哥 | 爆发期开始，成为主称呼 |
| 卷五 | 哥哥（峰值） | 偶尔「老公」，罕见 |
| 卷六 | 哥哥回落，转成「bro」「哥们」「老弟」 | 兄弟化收束 |

**两处要点**：

1. **「老公」全程只出现过几次，从未转正。** 比"从没叫过"更值得写——叫过，但没叫稳。这是这段关系没走完的那半步。
2. **「老弟」是他给她的降级爱称**，卷五她开始反叫他老弟，形成对称的玩笑。这是两个人之间最亲的一种疏远。

## 二、昵称：她的皮肤与他的标点

**她每年换一套人格。** 昵称不是名字，是皮肤，一年一换。换皮肤是她的表达欲续命方式。她甚至爱用版本后缀，像给商品打标签。

**他四年只换过三个标点。** 从不写字，只用符号。她的名字一换再换，他连名字都没有。

这一条是全书的隐藏时间轴，也是两个人性格的极简对照：**她的稳定靠换，他的稳定靠不换。**

写法：不解释。让读者自己在两个文件夹名字的并置里撞见。

## 三、表情与符号

- 两人早期共用一个默认表情（她的那个和他的那个是一对）。这是他们唯一的"情侣款"。
- 中期出现一个共同图腾表情，全库使用量第一，**替代了文字撒娇**。
- 后期她的武器变成三个反讽表情连发（笑着的那个、失望的那个），用表情说反话。
- 一个设备指纹：繁体字残留在早期只出现在一个号上。可以写"换了个输入法就像换了个身份"。

## 四、一天怎么过

**开场**：她赖床系（十点前后的"早"，紧跟着一句"好像不早了"）；他更早，独白式早安打卡。也有些日子直接甩一张截图开场，没有问候。

**白天**：她的碎片瀑布，一天几十条，单条一到六个字，不等回复，话题乱跳。

**高峰**：夜里。白天的话多半是表演，深夜才是真话时间。

**收尾**：晚安自带拌嘴环节（"我才不要和你说晚安"，最后仍然互道）。到卷六，收尾语从"晚安"变成"你先吃饭吧"。

**最重要的一条**：对话里的沉默是合法的。直接消失几个小时，双方默认不追责。

## 五、吵架流程（全书结构级的发现）

导火索五种：回复延迟、晚安前的不亲亲、游戏里被说菜、外部火气转嫁、存在感危机（"你是不是不在乎我了"）。

升级方式：她短句连射加脏话夸张化，威胁断联但不拉黑。他先防御（"？""啊"），再解释，最后滑进自我攻击式长文本。

**谁先低头**：情绪上总是她先软（几十秒内从"我很烦你"到"摸摸你"）；事件上总是他递台阶。

**和好机制：从不正式道歉。** 三条溶解路径：

1. 新话题覆盖
2. 亲亲复读机对战
3. **断联后自动复活——大冲突不吵，用消失解决**

**这条要写进全书**：他们的冲突解决率是零，关系存活率是百分之百。「断联又接上」本身就是他们的吵架方式。

## 六、深夜长谈的规律

时段：零点到三点，消息密度反而上升。

触发话题：原生家庭清算、自我价值审判、关系定义与去向、追求者处理、考试结果。

结构：她以短消息连射开场（问一句，没人回，隔二十分钟自己"哈喽"），中段独白流，每条一行不接对方话，结尾被现实掐断。

**最反抒情的一点**：她的悲剧感永远被她自己的作息和邻居打断（"楼上在电钻，我再睡会"）。这是全书最好的抗矫情机制——再大的痛，也会被一句废话截断。

他在这里的角色：人形树洞加复读机，偶尔贡献一句被引用好几年的话。

## 七、语言级铁律

1. **她的句子越短越真，他的字越多越慌。**
2. 骂人的词在这段关系里没有一次是真敌意。真正的敌意全用在父母、老师和那些倒卖的人身上。他们的温柔藏在责任语里（"我来找""你先吃饭"）。
3. 引用回复是有指纹的：她的引用必带一句自成一体的小评论；他引用完只回一个字或一个表情。
4. 撤回是她的语言器官。大量的"发了撤、撤了发"，可以表现为深夜打了一长段又删掉。
5. 仪式性宣告：他们反复互相宣告"戒掉某件共同的爱好"，像互相监督戒烟，然后互相破功。
6. 消失是合法的，回来第一句一定说废话。他们之间有一条没写出来的规矩：**回来的时候，不问为什么走。**

## 八、卷六的语调转向

卷六的语言必须变。她的句子从情绪化转为概念化（"这要看你如何定义不喜欢"），把关系当课题论证。这是最冷的一种说话方式。

同期他的日常语言变成事务体（"好""行""我叫我妈帮我看看"）。

两件事同期发生：她的句子变抽象，他的句子变短。热恋的语言退潮后，剩下的是办事的语法。
