# 写作口径

1. 每章 2200-2600 字。结构：一个具体动作开场 → 一段对话推进 → 一次情绪错位 → 章末一条短消息作钩。
2. 视角：第一人称「我」即陆迟。温遥的心理只通过她的打字方式、她的停顿、她的行动呈现，永不进入她的内心独白。
3. 语言：口语优先。可以碎，可以没头没尾，可以一句话只回一个字。禁止书面抒情腔铺满全章——抒情每章最多一处，且必须落在一个具体动作上。
4. 介质自觉：本作的房间是对话框。写"她正在输入"、写已读、写凌晨三点的在线状态、写消息被撤回到只剩一行提示。但不写真实软件名与界面专名。
5. 对话全部新写。允许保留对话的**形状**（她一分钟连发九条、他只回一个"嗯"、她凌晨忽然出现、他打完又删），字句必须全新。
6. 不写真实数字：年份、生日、分数、电话、学号、宿舍号、时间点、快递单号。用相对时间与模糊量级。
7. 地名、人名只用设定集里的虚构名。新增配角先入人物集。
8. 克制：不审判，不卖惨，不写性与裸露，不写现实政治与疫情政策细节。愤怒可以写，但不站上道德高地。
9. 章末钩子优先于章内高潮。让读者想翻下一章，而不是想鼓掌。
10. 连载检查：发布前全文搜索旧关键词，零命中方可发。

## 语气参照（不是照抄，是校准）

- 她的句子：短、冲、带脏字、把真话包在玩笑里。说"滚"的时候往往是想留。
- 他的句子：慢、绕、事后才想明白。最该说的那句话，永远晚一条消息。
- 旁白：不解释人物，只记录动作与时间。

## 每章自检

- [ ] 有一个具体的物件或动作
- [ ] 有一处五感
- [ ] 有一句能记住的原声对话（新写的）
- [ ] 章末留了钩
- [ ] 全文搜旧关键词，零命中
