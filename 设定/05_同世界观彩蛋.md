# 同世界观彩蛋

两本书在同一张地图上，同一段时间里。读者各自读，是两本书；放在一起读，是一张地图上的两个点。

## 一、先说个结论

《答案》现在**没有任何**指向《存档》的痕迹。检索结果：

| 检索项 | 正文/ 与 txt | 设定/ | git 历史 |
|---|---|---|---|
| 账号、换号、小号、删记录 | 0 | 0 | 0 |
| 存档、文件夹、快递单 | 0 | 0 | 0 |
| 程遥、陆迟、满座、空椅 | 0 | 0 | 0 |

`答案_全文_120章.txt` 里 `空椅` 出现过 2 次，都是"空着的椅子"这类普通用词（第 479 行"那张空椅子"、11326 行"空椅背上搭着一把伞"），跟账号名无关。

也没在 F:\？、F:\notes、D:\desk、D:\desktop、答案的 git 历史里找到那份 43 章回忆录原稿。

所以这件事要从零设计，不是从现成的接口接上去。下面是我设计的方案。

## 二、咬合点（只有一把钥匙）

**禾塘县同属雾山市，与南雾县是邻县。**

这一句就能把两本书焊在一起，而且不必动《答案》一个字。

- 禾塘到市里的班车要路过南雾，在县城停一站。
- 禾塘人说"去市里"，说的就是雾山。
- 于是两书共用：雾山后街夜市（李婆的糖水摊）、雾山大学、清水河、南雾老街（宋阿婆的小卖部）。
- 两书的世界时间线也对齐：沈聿与陆迟同龄，高中同届不同校。那年春天两个人都在家里上网课，一个回了南雾借址，一个留在禾塘。同一个春天，两个县城，互不相识。

## 三、可以借用的共用资产

只借"公共设施"和"功能性配角"，不借任何私有信物。

| 资产 | 《答案》里的身份 | 《存档》里的用法 |
|---|---|---|
| 宋阿婆 | 南雾老街小卖部，只记得谁买了什么，不站队 | 卷一，陆迟在南雾转车，买过一瓶汽水 |
| 李婆 | 雾山后街夜市糖水摊主，后街拆后转去前街口摆小车 | 卷六，主彩蛋落点 |
| 雾山大学 | 沈聿的大学 | 陆迟考研的目标/复试地点 |
| 后街 → 前街口 | 后街被拆，李婆挪到前街口 | 卷六正好能接上拆迁之后的时期 |
| 清水河 | 穿南雾县城的小河 | 禾塘的河可作它的"上游"意象 |
| 那行英文 | 叶老师小册子里的句子：把单词放进句子，把人放进日子 | 卷六，空教室黑板上出现，不解释来源 |

## 四、埋点表（写在《存档》里）

五处暗、一处明。前四处读者第一次读只觉得是普通场景，读到第五处才会回头。

| 编号 | 位置 | 内容 | 强度 |
|---|---|---|---|
| E1 | 卷一 第06-08章 | 寒假回家，班车在南雾停二十分钟。陆迟下车，在宋阿婆的小卖部买一瓶汽水。宋阿婆找零，顺口说前些天也有两个学生来买，一人一瓶，走了还回头。陆迟没在意 | 潜 |
| E2 | 卷二 约27章 | 程遥说她有个同学也在这条班车线上。两人聊到中转站，只提一句就过了 | 潜 |
| E3 | 卷三 约52章 | 陆迟去市里考试，第一次走过雾山后街，远远看见一个糖水摊，人很多，他没坐下 | 潜 |
| E4 | 卷五 约95章 | 考研择校。他说不出为什么填了雾山大学。程遥问，他说离家近 | 潜，但有回响 |
| E5 | 卷六 约110章 | 到雾山复试。后街已经封了，他在前街口找到那辆糖水小车。李婆给他盛一碗，说以前在里头那个棚子，有个人老爱坐角落里，一个人，来得很稳 | 明 |
| E6 | 卷六 约119章 | 复试那天走错教室。黑板没擦，留着一行英文：We put words into sentences, and put ourselves into days. 他站了一会儿，把门带上 | 明，最狠的一处 |

E5 与 E6 不解释、不点名、不写"后来我才知道"。读者读过《答案》自然会懂，没读过也不影响。

## 五、反向彩蛋（可选项，需要动《答案》）

要让彩蛋双向成立，得在《答案》里留两处极小的痕迹。两处都不到一百字，不新增人物、不影响情节。

**R1（建议加在第117章 后街拆）**

> 邻桌坐了个后生，一个人。他点了两碗糖水，只喝一碗，另一碗搁在手边，一直到凉。走的时候他把那碗没动的推回给李婆，说不用退钱，就搁着。
>
> 周野看了一眼，说这人有病吧。
>
> 我说，可能是给人留的。

**R2（建议加在第99章 老乡桌）**

> 周野说老乡会里新来了个禾塘的，从不来聚餐，只在群里抢红包，抢完还发个谢谢。我说那不挺好，省事。他说，你这人真没劲。

R1 是陆迟在《答案》里唯一的正面出场（无名、无对白，只有动作），R2 只是一句话。两处加起来不超过一百二十字。

严格说不改《答案》也成立：E1 到 E6 全部在《存档》一侧，读者从《存档》回头去找《答案》，看到李婆、宋阿婆、后街，自己就能拼上。反向彩蛋只是让拼图更紧。

## 六、纪律

1. 全书彩蛋总计不超过六处，每处不超过一个自然段。
2. 客串者一律不具名，不给情节功能，不与主角对话。
3. 不搬运对方的信物（纸星星、平安结、磁带、书签、海盐糖一律不进《存档》；快递单、文件夹、两个账号也不进《答案》）。
4. 两对主角永不相遇、永不知晓对方存在。R1 里陆迟与沈聿同处一摊，但不同桌、不交谈、不对视。
5. 彩蛋不做解释。不写"多年后我才知道"，不写"后来我读到一本小说"。
6. 时间线冲突以《答案》为准（后街已拆、李婆在前街口），《存档》让路。

## 七、不做的

- 不做"《存档》是《答案》里男主写的那本小说"这种层级设定。两本书平级，只有血缘。
- 不让两书人物互相打听、互相传话。
- 不写网络上的联动梗（如"双厨狂喜"式彩蛋），保持纯文本内的克制。
- 不在两书的宣传文案里点明同世界观。让读者自己发现。
