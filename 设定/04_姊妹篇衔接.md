# 姊妹篇衔接

《答案》与《存档》是同一个世界观里的两个故事。可以各自独立读，也经得起放在一起读。

- 《答案》是作者自己的故事。（已完结，不再改动）
- 《存档》写的是他一位同学的故事。（本工程的唯一工作对象）
- 两个男生在现实里是高中同班，所以两个故事长在同一张地图上。

## 一、两台摄像机

| | 《答案》 | 《存档》 |
|---|---|---|
| 机位 | 沈聿，看别人 | 闻迟，看自己 |
| 介质 | 纸 | 屏 |
| 时态 | 向后看，回望 | 实时，当场 |
| 语言 | 抒情，书面 | 口语，碎片 |
| 情绪温度 | 温 | 冷 |
| 核心句 | 我给的喜欢，都写在纸上 | 我们什么都聊过，就是没有一起生活过 |
| 结局动作 | 写信，封存一箱旧物 | 导出记录，留两份，删一份 |
| 信物 | 纸星星、随身听、平安结 | 快递单、托付物、文件夹 |

《答案》写“没说出口”，《存档》写“说了四年也没能落地”。

**最狠的错位**：《答案》写“他的魂魄走了”的时候，《存档》里那两个人已经重新联系上了，正在每周偷偷聊一次。沈聿看到的是真的，闻迟不说也是真的。

## 二、命名系统

两部的名字出自同一副手笔，但走两条不同的水脉。

| 角色 | 《答案》 | 《存档》 |
|---|---|---|
| 男主 | 沈聿（沈有深水，聿是笔） | 闻迟（闻是听见，迟是迟到） |
| 女主 | 江苒（江是水，苒是草木渐长） | 程遥（程是路程，遥是远） |

- 两个男主：一个负责写下来，一个负责听得太晚。
- 两个女主的尾字：苒是时间感，遥是时间与空间的双关。同方向，不同字，不同音。
- 《答案》的卷目是水（蝉鸣、回潮、潮汐、退潮）；《存档》的卷目是信号（雪花、重连、双影、深夜、时差、存档）。

四个主角，同一种命名习惯：都是独姓加单字名，名字本身就是一句话。

## 三、名字作为主题

《答案》里“名字”只被提过两次，都只是一句：一是开场注解江苒的名字，二是他写的小说结尾留了个空名字，等她看完再填。

《存档》把这件事抬成主题。她换过很多个名字：一个父母给的，后面那些都是自己起的。

- 真名：程遥。父母给的，说的是“这一路很远”。
- 最早的那个名字：她小时候起的，那时候谁都在。
- 最后那个名字：后来起的，那时候人走空了。

他把她的两个账号分别导出、分开放，其实是把这个人的两半摆进了两个柜子。全书最后一次整理文件夹，就是最后一次清点她的名字。

而更冷的一层是：她一生都在换名字，他在她那里只有一个名字，而且那个名字不是字，是一个标点。

## 四、结尾对仗

《答案》最后一句：**我是沈聿，这道答案，我写完了。**

《存档》最后一句：**我是闻迟，这份存档，我留了两份。**

同一副手笔，两种收尾。一个把话说尽，一个把话存住。

## 五、文本纪律

- 两部书之间不做互文引用。读者读不到对方的名字。
- 唯一的连接是结构上的呼应：同一套命名逻辑、同一组结尾句式、同一个母题（把一个人存起来）。
- 不写"这本书是那本书里的小说"这类设定。两部书没有层级关系，只有血缘。
