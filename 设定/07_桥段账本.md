# 桥段账本（写前必查）

两本书同世界观，共用地理与配角。**边界靠这份清单守。**

起因：第二卷曾把《答案》的"有我没我""操场二十圈""橘子汽水"带进《存档》。根因不是记性，是动笔时没有逐项核对出处。此文件即为那道核对。

## 一、写作时的硬规矩

**每一章动笔前，凡是要用到的句子、物件、桥段，先问一句：这是哪条线的？**

- 出处是焦以琳那十四万条记录（本书素材）→ 可用
- 出处是《答案》原版素材或《答案》正文 → 绝对不用
- 两边都没有、我自己编的 → 可用，且应当标为本书原创

写完一章，再回头扫一遍这四个词表。

## 四、查错流程（每十章跑一次）

1. 全库检索《答案》私有信物词表，命中即改
2. 全库检索标志性台词，命中即改
3. 章名与《答案》章名逐条比对
4. 核对本书自己的信物有没有前后矛盾
5. 结果记在 `大纲/进度.md` 的检查栏
